# Estructura del plan reescrito

Usar esta estructura salvo que el plan tenga otra que funcione y el usuario la quiera mantener (preguntarlo en el paso 5).

```markdown
# Plan · [Nombre de la app]

> Al día: [fecha y hora]. Solo lo que falta. Lo hecho, en [git / historial: ruta].
> Spec: [ruta o «no hay»]

**Índice:** 0. Pendiente de decidir · 1. Dónde estamos · 2. Lo que falta · 3. Decisiones · 4. Riesgos · 5. Dónde está cada cosa

## 0. Pendiente de que decida [usuario]
| Decisión | Opciones | Mi recomendación |
|---|---|---|

## 1. Dónde estamos
- Objetivo (1 frase):
- «Terminado» = [lista de sí/no]
- Estado comprobado hoy: [qué, con qué comando o pantalla]

## 2. Lo que falta (en este orden)
### Fase N — [nombre]
- Qué se ve al terminar:
- Archivos:
- Cómo se comprueba:
- [ ] Hecha · [ ] Enseñada y aprobada

## 3. Decisiones vigentes
### 3.1 Del usuario (tal cual las dijo)
### 3.2 Mis criterios (puedes cambiarlos)

## 4. Riesgos y avisos
| Riesgo | Qué pasa | Cómo se evita |
|---|---|---|

## 5. Cómo entrar y dónde está cada cosa
```
